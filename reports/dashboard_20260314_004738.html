높음 UX QR코드 없는 원터치 eSIM 설치 기능 도입 - 앱 내에서 복잡한 QR 스캔 과정 없이 1초 만에 eSIM을 직접 설치할 수 있는 UX 구현 로밍도깨비, 도시락eSIM, 플릿 등 주요 경쟁사들이 모두 QR코드 없는 간편 설치 기능을 도입하여 사용자 경험을 대폭 개선하고 있어, 유심사도 즉시 도입하지 않으면 경쟁 열위에 처할 위험이 큼
높음 기능 AI 기반 맞춤형 eSIM 플랜 추천 엔진 개발 - 여행 국가, 기간, 데이터 사용 패턴을 입력하면 최적의 플랜을 자동 추천하는 AI 기능 구축 도시락eSIM이 AI 맞춤 추천 기능으로 차별화를 시도하고 있으며, 복잡한 해외 데이터 플랜 선택 과정을 간소화하여 고객 만족도와 전환율 향상이 가능함
중간 기능 부가 서비스 확장 - 해외 무료통화 서비스(100분) 및 eSIM 선물하기 기능 도입하여 서비스 차별화 강화 도시락eSIM의 해외 무료통화 서비스와 플릿의 eSIM 선물 기능이 고객 가치 증대에 기여하고 있어, 유사한 부가 서비스로 경쟁력 확보 필요
중간 UX 실시간 eSIM 관리 대시보드 구축 - 데이터 사용량, 잔여량, 유효기간을 실시간으로 모니터링하고 사용 완료된 eSIM을 자동 정리하는 UI 개발 플릿과 Holafly가 실시간 모니터링과 eSIM 관리 UI 개선을 통해 사용자 편의성을 높이고 있어, 유심사도 관리 기능 강화로 고객 만족도 향상 필요
낮음 요금 타겟 고객별 맞춤형 할인 정책 도입 - 비즈니스 출장 고객 대상 쿠폰팩 및 첫 구매 고객 대상 할인 코드 제공 플릿의 비즈니스 회원 할인과 Holafly의 프로모션 코드가 고객 획득에 효과적이며, 세분화된 할인 정책으로 다양한 고객층 확보 가능
